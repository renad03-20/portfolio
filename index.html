My Projects

Google-like Search Pages

This project consists of three distinct HTML pages mimicking popular Google features: Google Search: A simple, centered search bar allowing users to search the web on Google. Google Images Search: A page designed to replicate Google Images' search functionality. Advanced Search: A form-based page that enables users to refine their Google search queries with advanced options. Each page uses a clean, responsive layout and includes basic HTML, CSS for styling, and JavaScript for handling form submissions and search redirects.

Rock Paper Scissors Game

This project is a web-based implementation of the classic Rock, Paper, Scissors game. Users can play against the computer by selecting one of the three options: Rock, Paper, or Scissors. The game logic determines the winner, and the player's score (wins, losses, ties) is tracked and saved in the browser using localStorage. The score can be reset at any time, and interactive buttons enhance the user experience. The layout is simple, clean, and responsive, making it easy to play on any device.

Weather App

This app fetches and displays real-time weather data using a clean graphical interface. It allows users to view the current temperature and weather conditions for any location. Designed with a minimal layout and responsive components using PyQt5, it showcases my ability to build GUI applications with live data integration.
